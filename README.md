# Landing Page Project: Saltmarsh Solar

A responsive landing page for a fictional rooftop-solar company, built with plain HTML, CSS and JavaScript (no frameworks).

**Live demo:** _add your GitHub Pages / Netlify / Vercel URL here_

## Features
- Sticky header with logo and Home / About / Services / Contact navigation
- Hero with headline, subtext and call-to-action button
- Services section (3 cards), testimonials (3 quotes), footer with contact info and social links
- **Light / dark theme toggle**: remembers your choice (localStorage) and follows your system setting on first visit
- Mobile hamburger menu (closes on link tap or Esc)
- Smooth scrolling, a sunrise animation in the hero, and scroll-reveal animations
- Responsive for mobile, tablet and desktop; respects `prefers-reduced-motion`

## Project structure
```
landing-page-project/
├── index.html   # page structure
├── style.css    # theme tokens, layout, responsive rules
├── script.js    # theme toggle, hamburger menu, scroll reveal
└── README.md
```

## Run locally
Open `index.html` in a browser. No build step needed.

## Deploy (GitHub Pages)
1. Create a public repo named `landing-page-project` and push these files.
2. Repo **Settings → Pages → Branch: main / root → Save**.
3. Your site will be live at `https://<your-username>.github.io/landing-page-project/`.
